# clinic_site

Универсальный демо-шаблон сайта для клиник и стоматологий.

## Что это

Лендинг-витрина «под клиники», который:

- Сейчас — демо «Денталия»: ссылка для холодных продаж, вход в воронку (см. бизнес-ТЗ в памяти).
- Дальше — легко перекрашивается под конкретного заказчика (логотип, цвета, телефон, услуги, врачи) через `js/config.js` и переменные в `css/variables.css`.

## Стек

- Чистый HTML/CSS/JS (без фреймворков).
- Деплой: Vercel.
- Telegram-бот — отдельная фаза, после релевантного урока курса.

## Структура

```
clinic_site/
├── index.html         — главная страница (одностраничник)
├── css/               — стили (variables.css + style.css)
├── js/                — скрипты (config.js + логика)
├── img/               — картинки и иконки
├── project.md         — что делаем и зачем (заполнится после Discovery)
├── CLAUDE.md          — правила работы для Claude
├── PLAN.md            — поэтапный план с чек-боксами
└── README.md          — этот файл
```
